# Version 1.1.1 — preprint

- **Release date:** 2026-08-31
- **Publication status:** preprint

## Mathematical status

The main theorem is proved using CFSG and the published classification and
factorization results cited in the manuscript. Corollary 3(iv) of
Liebeck--Praeger--Saxl (2000) applies to the constructed primitive product
action, and Theorem D with Remark 2 of Liebeck--Praeger--Saxl (1990) applies
to the 6-subset stabilizer used for alternating groups of degree at least 13.

## Changes in this version

This was a repository-maintenance release. The mathematical manuscript and
its 20-page PDF were unchanged from version 1.1.0.

## Reproducible computation

The repository contains data for 414 TomLib tables, 2,395 maximal-subgroup
classes, 73 `CMP`-positive tables, and 24 factor-free rows. The release assets
contain the PDF, source archive, and SHA-256 sidecar.
