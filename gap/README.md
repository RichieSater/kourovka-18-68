# GAP workspace

[`cmp_tom.g`](cmp_tom.g) implements an exact Table-of-Marks criterion. For a
maximal subgroup class `m`, it considers every subgroup class whose order is
the index of `M` in `G` and uses `IntersectionsTom(tom,m,c)[1]` to decide whether some pair of
conjugates has trivial intersection. The order formula then gives an exact
factorization.

[`generate-tomlib-scan.g`](generate-tomlib-scan.g) applies this test to all
414 names returned by `AllLibTomNames()` and writes the two TSVs in `data/`.

Run from this directory:

```sh
gap --quitonbreak -q tests/test-cmp-tom.g
gap --quitonbreak -q gap/generate-tomlib-scan.g
python3 tests/check-tomlib-scan.py
```

Pinned producer environment: GAP 4.15.1 and TomLib 1.2.11. Missing tables or
missing maximal/intersection data raise an error; they are never interpreted
as negative evidence.  Both producers remove stale outputs before loading
packages, enforce the exact versions, and are documented only with
`--quitonbreak`, so every GAP `Error` produces a failing process. Character
tables alone are not used.

[`factor_free_tom.g`](factor_free_tom.g) exhausts every core-free subgroup
class and every possible intersection class to decide whether a pinned
maximal subgroup has a core-free transitive factor.  The proof-critical and
cross-check rows are generated by
[`generate-factor-free-scan.g`](generate-factor-free-scan.g):

```sh
gap --quitonbreak -q tests/test-factor-free-tom.g
gap --quitonbreak -q gap/generate-factor-free-scan.g
python3 tests/check-factor-free-scan.py
```

The producer also verifies maximality, core-freeness, the almost-simple
socle, and the nontrivial order of the maximal subgroup's intersection with
that socle.

[`../tests/test-sp4-subfield.g`](../tests/test-sp4-subfield.g) is a separate
GAP 4.15.1 / AtlasRep 2.1.11 regression for the corrected graph-outer
symplectic action.  It verifies, for `S4(4).4`, a maximal subfield normalizer
of order 2880, socle intersection 720, degree 1360, socle supplementation,
and coverage of all three involution classes.
